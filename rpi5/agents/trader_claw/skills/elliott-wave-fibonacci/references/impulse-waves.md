# Impulse Waves: Rules, Extensions, Truncations, Diagonals

## The Three Hard Rules (violating any one invalidates the count)

1. **Wave 2 never retraces more than 100% of wave 1** (it cannot go below the start of wave 1 in an uptrend).
2. **Wave 3 is never the shortest** among waves 1, 3, and 5 (it can be the longest, or not - but never the shortest of the three).
3. **Wave 4 never overlaps wave 1's price territory** in a standard impulse (exception: diagonals, where overlap is allowed).

These are rules, not guidelines - if a user's count breaks one, the count is wrong, full stop. Make them find which rule breaks rather than telling them directly.

## Extensions

- One of the three motive waves (1, 3, or 5) is typically "extended" - elongated and subdivided into a more obvious 5-wave structure of its own, dwarfing the other two.
- Wave 3 is most commonly the extended wave, especially in strongly trending markets.
- If a user claims a count with no extension anywhere and roughly equal-length waves 1/3/5, treat that as unusual and probe for an alternative reading.

## Truncations

- Rare case: wave 5 fails to move beyond the end of wave 3 (a "failed fifth"), typically signaling exhaustion.
- Usually confirmed by weak momentum/volume on the wave 5 attempt. A truncation claim without momentum divergence to support it is speculative.

## Diagonals (Leading and Ending)

- A special 5-wave pattern where wave 4 *is allowed* to overlap wave 1 - it's the one context where the standard non-overlap rule is suspended.
- **Ending diagonal:** appears in wave 5 or wave C position, signals trend exhaustion, typically wedge-shaped, converging trendlines, overlapping waves.
- **Leading diagonal:** appears in wave 1 or wave A position, less common, similar overlapping structure but signals initiation, not exhaustion.
- If a user invokes "diagonal" to excuse an overlap, verify the wedge shape and position (must be wave 1, 5, A, or C) - "diagonal" is not a free pass for any overlapping structure.

## Probing Questions

- "Where exactly does your wave 4 sit relative to wave 1's high/low? Does it overlap?"
- "Which of your three motive waves is the shortest? Is it wave 3?"
- "Does wave 2 dip below the start of wave 1 anywhere on this chart?"
- "If you're calling this a diagonal, which position is it in - 1, 5, A, or C? Does the shape actually converge like a wedge?"
