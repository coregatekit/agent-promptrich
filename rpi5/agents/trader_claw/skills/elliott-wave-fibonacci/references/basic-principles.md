# Elliott Wave: Basic Principles

## The 5-3 Structure

- A complete cycle consists of a 5-wave **motive** phase (labeled 1-2-3-4-5) in the direction of the larger trend, followed by a 3-wave **corrective** phase (labeled A-B-C) against it.
- Motive waves 1, 3, 5 move with the trend (impulse legs); waves 2 and 4 are corrections within the motive phase.
- Corrective wave B moves against the correction's overall direction; A and C move with it.

## Motive vs. Corrective Mode

- **Motive mode:** subdivides into 5 waves, moves efficiently, less overlap.
- **Corrective mode:** subdivides into 3 waves (or combinations), choppier, more overlap, harder to label confidently in real time.

## Wave Degree

- Waves nest fractally: a Grand Supercycle wave 1 is itself composed of 5 smaller-degree waves, and so on down to the smallest observable timeframe.
- Standard degree labels (largest to smallest): Grand Supercycle, Supercycle, Cycle, Primary, Intermediate, Minor, Minute, Minuette, Subminuette.
- A count is only meaningful if the user specifies (even loosely) what degree they're labeling - "wave 3" means nothing without knowing whether it's Primary wave 3 or Minute wave 3.

## Labeling Conventions

- Motive waves: numbers (1, 2, 3, 4, 5), or lowercase roman numerals for a specific degree convention some analysts use.
- Corrective waves: letters (A, B, C), or (W, X, Y, Z) for combinations.
- Always ask the user to state the degree and starting point of their count - an ungrounded label is not falsifiable, which defeats the purpose of using EW at all.
