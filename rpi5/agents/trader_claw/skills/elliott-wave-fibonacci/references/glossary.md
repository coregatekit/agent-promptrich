# Elliott Wave & Fibonacci Glossary

- **Motive wave:** a 5-subdivided wave moving with the larger trend (positions 1, 3, 5 of an impulse, or A/C of a zigzag).
- **Corrective wave:** a 3-subdivided (or combination) wave moving against the larger trend.
- **Impulse:** the standard 5-wave motive pattern obeying the three hard rules (no >100% wave 2 retrace, wave 3 not shortest, no wave 1/4 overlap).
- **Diagonal:** a 5-wave motive-position pattern where wave 1/4 overlap is permitted; wedge-shaped; appears only in wave 1, 5, A, or C position.
- **Extension:** an elongated, clearly-subdivided motive wave, most often wave 3.
- **Truncation:** a failed fifth wave that doesn't exceed the end of wave 3.
- **Zigzag:** 5-3-5 sharp correction (A-B-C).
- **Flat:** 3-3-5 sideways correction; regular, expanded, or running variants based on wave B's reach.
- **Triangle:** 3-3-3-3-3 (A-B-C-D-E) converging (or rarely expanding) corrective pattern.
- **Combination:** two or more corrective patterns joined by X wave(s) - double/triple three.
- **Alt Count:** the next most credible alternative wave interpretation if the primary count is invalidated.
- **Alternation:** a guideline that consecutive corrections (e.g., wave 2 and wave 4) tend to differ in form/depth from each other.
- **Confluence:** multiple independent Fibonacci relationships clustering near the same price, strengthening a target's reliability.
- **Wave degree:** the fractal scale of a wave count (Grand Supercycle down to Subminuette).
